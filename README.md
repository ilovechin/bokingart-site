# Bokingart Overseas Website Demo

This is the first static overseas website demo for Bokingart / 铂晶艺术.

## Included

- English global homepage
- Official BOKING logo asset
- Catalog-backed source section using all six supplied PDF groups
- Product detail pages for artworks, furniture, lighting, and custom projects
- English SEO/GEO keyword and page-title plan
- Global inquiry section
- Mailto-based inquiry form
- Responsive layout
- Optimized local image assets
- SEO metadata
- JSON-LD structured data
- `robots.txt`
- `sitemap.xml`
- `llms.txt` for AI search / GEO context
- `seo-geo-plan.md`
- Privacy Policy and Terms of Use pages

## Pages

- `index.html`: homepage with brand overview, collections, catalog sources, projects, FAQ, and inquiry form.
- `artworks.html`: collectible synthetic crystal artworks.
- `furniture.html`: sculptural crystal furniture.
- `lighting.html`: crystal art lighting, chandeliers, wall lights, floor lamps, and table lamps.
- `custom-projects.html`: bespoke crystal art installations and project cases.
- `privacy.html`: privacy policy for global inquiries.
- `terms.html`: website terms of use.

## Live Launch

Current official free Netlify domain:

```text
https://bokingart.netlify.app/
```

Before upgrading to a custom domain, replace these placeholders as needed:

- Email: `contact@bokingart.com`
- Social links in JSON-LD `sameAs`
- Real company address, if public
- Final product names, dimensions, and project case details

## Local Preview

Open `index.html` directly, or run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve_site.ps1 -Port 8088
```

Then visit:

```text
http://127.0.0.1:8088/
```
